# Cost-Accounting-System(成本核算系统Web版)

## 系统介绍  
第二炼轧厂精量化成本核算系统系统主要包括了1780精量化成本核算系统系统、炼钢精量化成本核算系统系统、炉卷精量化成本核算系统系统。炼钢精量化成本核算系统系统为1780精量化成本核算系统系统、炉卷精量化成本核算系统系统提供炼钢水平附加，使得两条轧线的板坯计划价更符合实际。 

## 软件设计框架

分为以下5大部分，每一部分可以自动增删改查，导入/导出excel表格，使得系统数据可以在本系统中呈现以及保存，为后期做进一步成本预测，多环节联动提供数据基础；
